# Guía visual de FixCampus

La landing, el acceso y los módulos de administración usan la misma paleta y los mismos controles de Angular Material.

| Elemento                 | Valor                                                     |
| ------------------------ | --------------------------------------------------------- |
| Acción principal         | Verde oscuro #0D6A62 con texto blanco                     |
| Fondo                    | #F8F9FA                                                   |
| Tarjetas                 | Blanco con borde #D6DBDE y radio de 14 px                 |
| Texto                    | #212529                                                   |
| Texto secundario         | #5F6B70                                                   |
| Mensaje de error         | Texto #9D2B21 sobre #FDECEA                               |
| Mensaje de éxito         | Texto #17633B sobre #E5F6EC                               |
| Títulos                  | Poppins, 28 px para título de página y 19 px para sección |
| Texto y controles        | Open Sans, 15 px                                          |
| Espaciado entre tarjetas | 16 px                                                     |
| Paginación               | Angular Material, 5, 10 o 25 registros por página         |

La marca se muestra como texto y las pantallas de acceso usan una fotografía del campus Monterrico. La imagen procede de Wikimedia Commons y su autor la publicó con CC0.
https://commons.wikimedia.org/wiki/File:Universidad_Peruana_de_Ciencias_Aplicadas_-_Sede_Monterrico.png

Las acciones se nombran Ver detalle, Editar, Eliminar, Guardar y Cancelar. La eliminación pide confirmación. Los errores aparecen junto al campo correspondiente o como aviso si los devuelve el servidor.

En celular las tarjetas se apilan y las tablas permiten desplazamiento horizontal. Los campos conservan su etiqueta y los botones se pueden recorrer con teclado.

Las coordenadas se guardan en el catálogo de ubicaciones. El mapa muestra ese punto y conserva el crédito de OpenStreetMap. Si faltan coordenadas, se indica qué dato falta. Una ubicación de demostración se identifica como DEMO.

La sugerencia de Gemini se solicita desde Nueva incidencia. El usuario puede aceptar la categoría, cambiarla o seleccionarla a mano. Una respuesta sin coincidencia, una cuota agotada y una falla de conexión tienen mensajes distintos.

Las capturas y las comprobaciones están en [la revisión del 12 de noviembre](revision-12-11-2026.md).
