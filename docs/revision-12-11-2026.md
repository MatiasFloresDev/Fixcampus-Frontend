# Revisión del 12 de noviembre

Se revisó la retroalimentación de la clase y se probaron los cambios con Angular en el puerto 4200 y Spring Boot en el 8080.

| Lo que se pidió                             | Cambio y comprobación                                                                                                                                                                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Completar el mantenimiento de las entidades | Usuarios permite crear, consultar el perfil, editar y eliminar. Usa los roles que entrega el backend. Categorías, ubicaciones y roles conservan su mantenimiento. Los reportes permiten gestionar comentarios, recomendaciones y enlaces de evidencias. |
| Validar los campos                          | Los formularios muestran los campos obligatorios, límites y errores. Se probaron campos vacíos, correo inválido y enlaces de evidencias que no usan HTTP o HTTPS. Al editar una cuenta, dejar la contraseña vacía conserva la actual.                   |
| Paginar los listados                        | Usuarios, reportes, recomendaciones, comentarios, evidencias y catálogos tienen paginación de 5, 10 o 25 elementos. Al buscar se vuelve a la primera página y al eliminar se ajusta la última página.                                                   |
| Mostrar las dos APIs funcionando            | Gemini sugirió Electricidad para «El foco del pasillo no enciende». Se aceptó la sugerencia en el formulario. OpenStreetMap cargó las imágenes del mapa para una ubicación de demostración.                                                             |
| Mantener el mismo diseño                    | Se ajustaron los colores de Material, mensajes, tarjetas y acciones. La guía está en [guia-estilos.md](guia-estilos.md). Usuarios se revisó a 390 px sin desbordamiento horizontal.                                                                     |
| Llevar evidencias a Trello                  | Las capturas están en esta carpeta y las tarjetas conservan sus identificadores, miembros y estimaciones. La revisión del equipo sigue pendiente.                                                                                                       |

## Comprobaciones

- `npm test -- --watch=false`: 14 pruebas aprobadas. Incluyen paginación y búsqueda de usuarios, edición sin cambiar contraseña, validación de evidencias y permisos de las pantallas.
- `npm run build:render`: compilación correcta. Quedan advertencias por tamaño inicial de 791,59 kB y por Leaflet en CommonJS; no impiden compilar.
- Backend, `mvnw.cmd test`: 6 pruebas aprobadas.
- Prueba local de 40 peticiones HTTP: altas, consultas, cambios y bajas con datos temporales; rechazo de correo duplicado y URL inválida; 403 para reportes ajenos y módulos administrativos; 409 al eliminar registros que siguen relacionados. Los registros temporales se eliminaron al terminar.

Los tests de Angular usan respuestas simuladas. La prueba HTTP, Gemini y el mapa se comprobaron contra los servicios reales indicados arriba.

## Para la siguiente demostración

En la base local se dejó el reporte **DEMO - Luminaria del campus**, asociado a **DEMO Monterrico**. El punto es una referencia aproximada del campus y el reporte es ficticio. Las ubicaciones que ya existían se conservaron; cada una necesita sus coordenadas reales para mostrar un punto correcto.

Antes de presentar en Render hay que comprobar allí la URL del backend, CORS, la variable de Gemini y los datos de ubicación. Esta revisión comprueba el entorno local y la compilación para Render; no certifica el despliegue remoto.

El equipo debe recorrer sus historias en el entorno que va a presentar, adjuntar sus evidencias y cerrar las tarjetas que correspondan. No se debe marcar una historia completa solo porque el código ya esté integrado.
