Antes de dar una pantalla por lista

  • Usar los mismos colores, fuentes, botones y etiquetas.
  • Preparar los estados normal, cargando, vacío, error y confirmación que correspondan.
  • Mostrar los campos con sus etiquetas y permitir el uso con teclado.
  • Revisar escritorio, celular y mensajes largos.
  • Guardar el mockup de cada módulo en la página de su integrante.
